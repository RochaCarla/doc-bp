# Reuniões

**Gem**: `decidim-meetings`

O módulo de reuniões permite organizar encontros presenciais ou virtuais dentro de espaços participativos.

## Funcionalidades

- **Agendamento** — definição de data, horário, local e tipo (presencial, virtual, híbrido)
- **Inscrição** — participantes se inscrevem com controle de vagas
- **Atas** — registro de ata e resultados após a reunião
- **Integração com videoconferência** — link para sala virtual (Jitsi, Zoom, etc.)
- **Geolocalização** — mapa com localização do encontro presencial
- **Convites** — envio de convites a participantes específicos

## Configuração

| Opção | Descrição |
|-------|-----------|
| **Inscrições habilitadas** | Permitir que participantes se inscrevam |
| **Limite de vagas** | Número máximo de inscritos |
| **Criação por participantes** | Permitir que participantes criem reuniões |
| **Comentários habilitados** | Permitir discussão sobre a reunião |
