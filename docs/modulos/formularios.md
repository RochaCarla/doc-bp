# Formulários

**Gems**: `decidim-surveys` + `decidim-forms`

O módulo de formulários permite criar enquetes e questionários customizáveis dentro de espaços participativos.

## Funcionalidades

- **Perguntas variadas** — texto curto, texto longo, escolha única, múltipla escolha, escala, matriz
- **Lógica condicional** — exibir perguntas com base em respostas anteriores
- **Obrigatoriedade** — marcar perguntas como obrigatórias ou opcionais
- **Anonimato** — respostas podem ser anônimas
- **Exportação** — download das respostas em CSV, JSON ou Excel

## Tipos de Pergunta

| Tipo | Descrição |
|------|-----------|
| Texto curto | Resposta em uma linha |
| Texto longo | Resposta em múltiplas linhas |
| Escolha única | Seleção de uma opção (radio) |
| Múltipla escolha | Seleção de várias opções (checkbox) |
| Ordenação | Ordenar opções por preferência |
| Matriz | Grade de perguntas com opções em colunas |
| Separador | Divisor visual entre seções |
| Título | Cabeçalho de seção |
