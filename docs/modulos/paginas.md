# Páginas

**Gem**: `decidim-pages`

O módulo de páginas permite publicar conteúdo estático informativo dentro de espaços participativos.

## Funcionalidades

- **Editor rico** — formatação com cabeçalhos, listas, links, imagens e vídeos
- **Comentários** — discussão opcional sobre o conteúdo da página
- **Multilíngue** — conteúdo traduzível para os locales configurados

## Uso Típico

- Publicar regras e termos de participação
- Compartilhar contexto e informações de referência
- Disponibilizar documentos e materiais de apoio ao processo
