# decidim-module-common_questions

**Tipo**: Componente customizado (LAPPIS/UnB)
**Repositório**: [components-brasil-participativo](https://gitlab.com/lappis-unb/decidimbr/components-brasil-participativo)

Componente que permite criar e gerenciar perguntas frequentes (FAQ) compartilhadas entre múltiplos processos participativos.

## Funcionalidades

- **FAQ centralizado** — perguntas e respostas reutilizáveis em diferentes espaços
- **Categorização** — organização por temas
- **Gerenciamento via admin** — criação e edição pelo painel administrativo
- **Compartilhamento** — mesma pergunta pode ser exibida em múltiplos processos

## Motivação

Muitos processos participativos geram as mesmas dúvidas dos cidadãos ("Como participo?", "Como funciona a votação?"). Em vez de duplicar FAQs em cada processo, este componente permite manter uma base centralizada e reutilizável.
