# decidim-module-questionnaires

**Tipo**: Componente customizado (LAPPIS/UnB)
**Repositório**: [components-brasil-participativo](https://gitlab.com/lappis-unb/decidimbr/components-brasil-participativo)

Componente que estende o módulo nativo de questionários do Decidim (`decidim-surveys`/`decidim-forms`) com funcionalidades adicionais.

## Funcionalidades

- **Tipos de pergunta adicionais** — extensões além dos tipos padrão do Decidim
- **Validações customizadas** — regras de validação específicas para o contexto brasileiro
- **Exportação aprimorada** — formatos de exportação adicionais ou melhorados
- **Integração com outros módulos** — vinculação de respostas a propostas ou processos

## Relação com o Módulo Nativo

Este componente **não substitui** o módulo nativo de formulários (`decidim-surveys`). Ele o **estende** com funcionalidades que não existem no Decidim upstream, mantendo compatibilidade com a base.
