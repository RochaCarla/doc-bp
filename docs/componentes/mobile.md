# decidim-mobile

**Tipo**: Componente customizado (LabLivre/UnB)
**Gem no core**: `decidim-mobile` (branch `main`)
**Repositório**: [decidim-module-mobile](https://gitlab.com/lappis-unb/decidimbr/bp-mobile/decidim-module-mobile)

Módulo de suporte ao aplicativo móvel do Brasil Participativo, mantido no grupo `bp-mobile`.

## Uso no core

- Instalado via `Gemfile` a partir da branch `main`.
- O repositório do core também referencia o módulo em `vendor/decidim-module-mobile`.

!!! note "Instalação como PWA"
    Desde fevereiro de 2026 o site não pode mais ser instalado como PWA pelo navegador.
